# HeroicLibrary: Updated

Provides the shared helpers needed by Heroic mods. This is a dependency library, rather than a separate gameplay overhaul.

Requires Factorio 2.1.24 or later. Enable the dependencies listed in the mod manager. This fork keeps the original mod’s content rather than introducing a new balance model.

Existing saves using heroic_library can migrate to this mod identity. Keep a backup when changing a mod set, and disable the original when selecting this fork.

Original mod: [ heroic_library ](https://mods.factorio.com/mod/heroic_library). Original author credits and applicable license notices are retained in the source package.
